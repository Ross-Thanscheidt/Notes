## User Environment Variables

These environment variables are used along with my customized keyboards ([Keychron Pro 8](https://github.com/Ross-Thanscheidt/qmk_firmware/tree/wireless_playground_ross/keyboards/keychron/k8_pro/ansi/rgb/keymaps/Ross-Thanscheidt) and [Keychron Q3 Max](https://github.com/Ross-Thanscheidt/qmk_firmware/blob/wireless_playground_ross/keyboards/keychron/q3_max/ansi_encoder/keymaps/Ross-Thanscheidt/keymap.c))
so I can launch Windows Terminal using the specified Profile (`Caps Lock`+`0` through `Caps Lock`+`9`):

| Variable | Value |
| :--- | :--- |
| `WT`   | `%LocalAppData%\Microsoft\WindowsApps\Microsoft.WindowsTerminalPreview_8wekyb3d8bbwe\wt.exe --window 0 new-tab --profile` |
| `WT_1` | `PowerShell 7` |
| `WT_2` | `Command Prompt` |
| `WT_3` | `Dev PS for VS 2026 Insiders` |
| `WT_4` | `Dev CMD for VS 2026 Insiders` |
| `WT_5` | `Dev PS for VS 2026` |
| `WT_6` | `Dev CMD for VS 2026` |
| `WT_7` | `Git Bash` |
| `WT_8` | `AlmaLinux-10` |
| `WT_9` | `*Dev PS for VS 2026 Insiders` |
| `WT_0` | `*Dev CMD for VS 2026 Insiders` |
