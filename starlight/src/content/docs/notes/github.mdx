[GitHub CLI Repository](https://github.com/cli/cli)  
[GitHub CLI Manual](https://cli.github.com/manual/)  
[GitHub REST API Documentation](https://docs.github.com/en/rest)

- `gh config list`
- `gh config set editor vim`
- `gh auth status`
- `gh auth login`
- `gh repo list`
- `gh release list --repo vim/vim-win32-installer`
- `gh release view --repo vim/vim-win32-installer --json body --jq ".body"`
- Set `GH_HOST` environment variable to `github.com` or FQDN of GitHub Enterprise server

## Viewing Issues

Use these JavaScript commands simulate mouse clicks to show more content for an Issue, Discussion, or Pull Request page:

### Load More

Click all of the **Load more...** button links on the page to load all hidden conversations:

```JavaScript
javascript:function ShowHiddenConversations(){if(document.querySelectorAll('.ajax-pagination-btn').length){document.querySelector('.ajax-pagination-btn').click(); window.setTimeout(ShowHiddenConversations, 100);}} ShowHiddenConversations();
```

### Show Previous Replies

Click all of the **Show # previous replies** button links on the page to list all reply comments:

```JavaScript
javascript:document.querySelectorAll('.TimelineItem--condensed .Button--link').forEach(ch => { ch.click() })
```

### Show Comments

Click on all of the **Show comment** button links on the page to show all comments:

```JavaScript
javascript:document.querySelectorAll('.Details-content--closed').forEach(ch => { ch.click() })
```
